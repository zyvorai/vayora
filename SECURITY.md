# Security policy

Report vulnerabilities privately through GitHub Security Advisories on this repository
(Security tab -> Report a vulnerability). Do not open public issues for security problems.

- We acknowledge reports within 72 hours and aim to give a remediation plan within 14 days.
- Please give us reasonable time to fix before disclosure; we credit reporters who want it.
- Out of scope: findings that need a compromised host or operator, and anything on third-party providers.

The design, controls and known gaps are in [docs/zyvor/THREAT_MODEL.md](docs/zyvor/THREAT_MODEL.md).
Supported version: the latest commit on `main` (pre-1.0).
